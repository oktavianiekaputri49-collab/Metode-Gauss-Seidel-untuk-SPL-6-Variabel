# Metode-Gauss-Seidel-untuk-SPL-6-Variabel
Penyelesaian Sistem Persamaan Linear (SPL) 6 variabel menggunakan Metode Gauss-Seidel secara iteratif dengan toleransi error 0,05% dan batas 20 iterasi. Project ini membahas proses konvergensi, perhitungan error relatif, serta implementasi metode numerik menggunakan Microsoft Excel.
